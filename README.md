# Harmon Vision for River Cess 2029 Campaign Website

Official campaign website for Hon. Noko Benjamin Harmon, candidate for Representative of River Cess County, Liberia 2029.

## Features

- Mobile-first responsive design
- Fixed navigation header with smooth scrolling
- Interactive mobile menu with toggle
- Candidate profile with image display
- Campaign platform presentation
- Contact information and social media links
- Newsletter subscription
- Login functionality for campaign staff
